# **App Name**: RentEasy

## Core Features:

- Secure Login: OTP-based login via mobile number for secure access.
- Property Listing: Display property listings with type (house, villa, flat), location photos, room/kitchen/front views, owner/agent mobile number, BHK type, suitability (family/bachelor), and monthly rent amount.
- Advanced Search: Enable users to search properties by city/area, BHK type, rent range, and family/bachelor preference.
- Property Upload: Allow owners/agents to list properties with photo uploads and detailed information.  Include a listing preview.
- AI Property Description: Generate a tool to create short descriptions of the property listing for the upload feature, from the uploaded pictures, to make appealing ads.  
- Save Listings: Allow the user to save favorite properties for comparison and later viewing.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) for a calming and trustworthy feel.
- Background color: Very light blue (#F0F8FF), almost white, to keep focus on the property photos and minimize distraction.
- Accent color: Soft green (#90EE90) to highlight key interactive elements.
- Font pairing: 'Poppins' (sans-serif) for headings and 'PT Sans' (sans-serif) for body text to maintain modern, clean readability.
- Simple, outline-style icons for property types and filter options, following the modern conventions from SearchHome India.
- Mobile-first, grid-based layout, optimized for visual appeal and usability.
- Subtle transitions and animations on property listings for user engagement.
